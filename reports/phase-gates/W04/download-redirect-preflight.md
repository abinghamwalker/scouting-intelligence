## Decision

The source authority permits exactly one HTTP 302 from an already allowlisted
`ndownloader.figshare.com/files/{file_id}` URL to the corresponding exact
`s3-eu-west-1.amazonaws.com/pfigshare-u-files/{file_id}/{name}` path. The algorithm,
credential scope, signed headers, date, expiry, signature shape, and exact query-key
set must validate. Credential scope separators must use the observed literal `/`
representation; percent-encoded separator aliases are denied. Expiry is capped at 60
seconds.

Different hosts, regions, buckets, object paths, file identities, query keys,
algorithms, credential scopes, signed headers, missing signatures, excessive expiry,
userinfo, ports, fragments, or a second redirect remain denied.

This bounded hop fetches the same Figshare object into guarded local storage. It does
not authorise cloud storage, post-acquisition network transfer, credentials, accounts,
hosted services, public endpoints, deployment, or any new source.
