# W05 acceptance report

- Date: `2026-08-03`
- Phase: `W05 — Features, roles and transparent M0 retrieval`
- Decision: **VERIFIED_AND_READY_FOR_CHECKPOINT**
- P0/P1 blockers: **none**

W05 has produced the deterministic, reloadable, explainable and role-aware M0
retrieval baseline required by G-W05. All producer packets were master-reviewed,
all material implementation surfaces received an independent review, and the final
complete repository gate passed 2,695 tests with no failures.

The accepted feature registry binds exact feature definitions, types, units, order,
denominators, state policies, temporal rules and dependency lineage. Its W04 bridge
continues to admit only `action_count`, `coordinate_known_action_count`,
`match_count` and `resolved_possession_action_count`. W04 minutes, rates and per-90
features remain suppressed because there is no accepted elapsed-minutes denominator;
suppression, unavailability, missingness and observed zero remain distinct.

The broader six-feature resemblance family and its metadata controls are explicitly
constructed synthetic-development evidence. They are not Wyscout-derived production
features. The selected role-aware restriction scores `1.0` precision@3 on the single
fixed comparison, exceeding the declared metadata (`0.1111111111111111`) and raw
Euclidean (`0.3333333333333333`) controls. This establishes baseline readiness only.
W06 owns protected evaluation, robustness intervals and any stronger evidence claim.

The responsibility taxonomy is contextual and probabilistic, binds version `v1`, and
does not turn roles into permanent player labels. External expert validation was not
performed. Exemplar similarity remains only an additional query signal and cannot
replace the falsifiable taxonomy.

One shared serving core supplies batch and request paths with one loader, feature
schema, transformation/scorer, restriction/filter path, confidence projection,
reason-code system, deterministic tie order and result digest. It returns the six
evidence dimensions and separate data-confidence evidence under the
`resemblance_only` boundary; it does not emit an unsupported blended match
percentage. Serving cannot fit, mutate artifacts or access provider data.

The accepted P2 representation residuals do not change results, rankings, evidence,
lineage or claims. Generated PYC/cache and equivalent host-state observations remain
the already deferred W10 concern and did not justify a W04 authority mutation. W06
has not begun.

The master authorises the prescribed local integration commit, annotated
`checkpoint/w05-accepted` tag and checkpoint-ledger commit. No remote, publication,
deployment, service, credential, provider access or new dependency is involved.
