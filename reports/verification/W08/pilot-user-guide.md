# W08 guided pilot user guide

## What the pilot is for

The pilot proves that one complete local workflow can move from a role brief through
approval, scout review, meeting decisions, evidence export and safe recovery. It does
not assess a real player, validate model quality or make a recruitment recommendation.

## The two local pages

- **Guided pilot application:** complete the workflow. A persistent green pilot bar
  shows the current synthetic role, changes role with one click and opens the journey
  guide. Passwords are only a manual fallback.
- **Study Console:** start/stop the runtime and record the truthful T1–T7 outcomes,
  timings, assistance, observations and receipts. Use **Record results** in the pilot
  bar to return to it.

Do not manually copy ports, actor IDs or passwords during a guided pilot. Do not open
multiple workflow records when the guide says to continue the current one.

## Guided journey

1. **T1 — Analyst:** create one role brief, open it and submit it.
2. **T2 — Approver → Analyst:** approve that same brief, switch back and create its
   replayable retrieval link.
3. **T3 — Analyst → Scout:** create one shortlist, add one synthetic candidate, assign
   it to the synthetic Scout, append a structured observation and append an amendment.
4. **T4 — Approver:** exercise hold, rejection and reconsideration with controlled
   reasons; confirm all revisions remain visible.
5. **T5 — authorised role → Admin:** create and inspect the local evidence pack, then
   confirm the Admin path is denied without disclosing protected content.
6. **T6 — current role + Study Console:** expire the exact session and exercise
   conflict/failure recovery without partial records.
7. **T7 — any authorised role:** use keyboard-only navigation, inspect the narrow
   layout and correctly state the claim boundary.

After each task, choose **Record results** and save the outcome honestly. Guidance is
allowed in a development pilot, but record the assistance count and usability finding.
A submitted pilot capture remains pending until its receipts and identifiers reproduce
and independent G-W08A review passes.

## If the old password-driven screen is still open

That runtime was started before guided mode was loaded. Preserve it as a usability
finding, stop it safely in the Study Console, restart the Study Console, and start a
new pilot slot. The prior capture is not silently rewritten or counted as a pass.
